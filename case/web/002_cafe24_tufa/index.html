Concept

제품이 화면의 주인공이 되도록 장식을 덜어내고, 고객이 ‘보고 → 비교하고 → 담는’ 흐름에 집중한 화면을 설계

Approach

그리드 중심 레이아웃 — 상품을 얇은 선으로 나뉜 4열 그리드에 정렬해, 상품이 많아도 한눈에 비교할 수 있게 구성. 모바일은 2열로 전환해 작은 화면에서도 탐색이 편하도록 설계

가격 정보 동선 설계 — 할인 기간 → 상품명 → 정가 → 할인율·판매가 순으로 정보를 배치해, 고객이 위에서 아래로 읽는 순간 구매 판단이 끝나도록 정리

Result

상품이 늘어나도 레이아웃이 흐트러지지 않아, 오픈 이후의 관리 부담까지 줄였습니다.
