Concept

환자는 병원을 고를 때 장비나 이력보다 "아플까?", "과잉진료는 없을까?"를 먼저 확인. 홈페이지의 목적을 '병원 소개'가 아닌 '상담 문의 전환'에 두고, 환자의 불안을 신뢰로 바꾸는 것을 핵심 목표로 설정.

Approach

  • 신뢰감 있는 차분한 컬러 — 딥 네이비와 맑은 스카이 블루로 의료 전문성과 청결함을 표현하고, 밝은 섹션과 어두운 섹션을 교차해 긴 페이지에서도 지루하지 않은 리듬 구성
  • 환자의 언어로 쓴 카피 — "아프지 않게, 필요한 만큼만.", '신경치료가 무섭다면?'처럼 전문 용어 대신 환자가 실제로 하는 걱정을 문장으로 풀어 첫 화면부터 공감 형성
  • 얼굴이 보이는 신뢰 — 의료진을 세로형 프로필로 크게 배치하고 다음 원장님이 살짝 보이게 해, 넘겨보며 병원의 사람을 자연스럽게 알아가도록 구성

User Flow

불안 해소 → 진료 이해 → 의료진 신뢰 → 공간 확인 → 방문 결정 순서로 섹션 배치. 전화·카카오톡 상담, 야간진료 안내, 고정 상담 메뉴를 스크롤 곳곳에 두고 모바일에서는 하단 탭바로 전환해, 어느 지점에서 마음이 움직여도 한 번에 문의로 이어지도록 설계.
